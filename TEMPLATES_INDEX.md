## 🔄 CRUD Synchronization Protocol

Whenever a product or component is added, modified, recolored, or removed:
1. **Catalog Update**: Add or modify its corresponding row in the Master Inventory Table above.
2. **Deliverable Packaging**: Verify that `ZIP/<slug>.zip` contains the latest code, assets, and buyer `README.md`.
3. **Store Listing**: Keep `STORE_LISTING/<Category>/<slug>.md` synchronized with pricing, tags, and descriptions.
4. **Live Deployment**: Re-deploy compiled static assets to Surge (`npx surge <dir> <domain>.surge.sh`).
5. **Scriptly Store Sync**: Invoke `POST` or `PATCH` on `https://scriptly.store/api/agent/products/<slug>` with `AGENT_API_KEY`.
6. **21st Alignment**: Publish updated interactive demo via `21st publish` and record in `EMAIL_REPLY_DAVID_21ST.md`.
7. **Git Push Rule**: Execute `git add . && git commit -m "..." && git push origin main` after completing the operation.
