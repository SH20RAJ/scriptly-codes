# Developer Portfolio Pro — Staff Engineer & Systems Architect Template

A production-grade, ultra-clean portfolio template engineered for senior software engineers, distributed systems architects, and technical leaders who want to convert high-ticket consulting retainers and executive engineering opportunities.

## 🌟 Key Features
- **Modern Obsidian & Neon Aesthetic**: Tailored dark-mode styling with subtle ambient glow and zero eye-strain contrast.
- **Interactive Terminal Simulator**: Showcases live metrics, cluster health, and command outputs.
- **Flagship Project Cards**: Highlight technical complexity with sub-millisecond latency badges, tech stack tags, and live links.
- **Impact-Driven Career Timeline**: Focuses on measurable business and technical metrics (uptime SLAs, cost savings, RPS throughput).
- **Architectural Tooling Radar**: Displays core technologies, distributed consensus protocols, and infrastructure mesh.
- **Zero Build Friction**: Pure HTML5, Tailwind CSS via CDN, and Lucide icons. Simply open `index.html` or deploy with one command to Surge, Vercel, or Netlify.

## 🚀 Quick Start
1. **Local Preview**:
   Double click `index.html` in your browser or run:
   ```bash
   npx serve .
   ```

2. **Customization**:
   - Open `index.html` and edit the name, titles, projects, and contact email.
   - Adjust accent colors in the `tailwind.config` block.

3. **Instant Deployment**:
   ```bash
   # Deploy to Surge in 5 seconds
   npx surge . my-developer-portfolio.surge.sh
   ```
