# Fine Dining & Modern Bistro — Artisanal Hospitality HTML5 Template

A luxurious, editorial web template engineered for Michelin-starred fine dining establishments, contemporary bistros, luxury cocktail lounges, and boutique hospitality venues looking to project culinary prestige and drive high-intent VIP table reservations.

## 🌟 Key Features
- **Cinematic Culinary Dark Palette**: Deep charcoal obsidian paired with luminous French champagne gold accents.
- **Interactive VIP Table Reservation Modal**: Captures party size, seating area (Chef's Counter, Main Dining, Pergola Garden), date/time, and dietary restrictions.
- **Autumn Tasting Menu Showcase**: Course-by-course presentation with sommelier wine pairing notes and dietary badges.
- **Chef's Philosophy & Farm Provenance**: Narrative storytelling sections celebrating organic local farm sourcing and wood-fired gastronomy.
- **Michelin & James Beard Acclaim Callouts**: High-authority award badges and national dining publication pull-quotes.
- **Pure HTML5 & Tailwind CSS**: Zero npm dependencies or build steps. Unzip, edit menu items, and deploy immediately.

## 🚀 Quick Start
1. **Local Preview**:
   Double click `index.html` or run:
   ```bash
   npx serve .
   ```

2. **Customization**:
   - Update courses, pricing, and wine pairings in `index.html`.
   - Connect the reservation modal to your OpenTable, Resy, SevenRooms, or email endpoint.

3. **Instant Deployment**:
   ```bash
   npx surge . my-fine-dining-bistro.surge.sh
   ```
