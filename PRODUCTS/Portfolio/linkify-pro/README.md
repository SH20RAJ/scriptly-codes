# 🚀 LINKIFY PRO — Developer Showcase & Multi-Tool SaaS Template

An ultra-sleek, modern developer link hub, personal branding showcase, and bio SaaS landing page built with **Next.js 14**, **Tailwind CSS**, **Framer Motion**, and **shadcn/ui**.

Live Demo: [https://linkify-pro.surge.sh](https://linkify-pro.surge.sh)  
Official Store Listing: [https://scriptly.store/products/linkify-pro-showcase](https://scriptly.store/products/linkify-pro-showcase)

---

## ✨ Features
- **Cinematic Dark Theme**: Deep obsidian backdrop with dynamic radial gradients and text hover glow effects.
- **High-Performance Bento Layout**: Interactive product feature grids, project showcases, and live analytics preview cards.
- **Micro-interactions**: Fluid framer-motion container delays, scroll physics, and sleek button interactions.
- **Authentication & Database Ready**: Pre-wired integration patterns for Clerk and Prisma ORM.
- **Responsive by Design**: Flawless pixel-perfect layout across mobile, tablet, and ultra-wide displays.
- **Zero Config Setup**: Clean dependency tree with TypeScript and standard Next.js App Router.

## 🚀 Getting Started

### 1. Installation
Install the project dependencies using your preferred package manager:
```bash
npm install
# or
pnpm install
# or
yarn install
```

### 2. Environment Configuration
Copy the example environment configuration:
```bash
cp env.example.txt .env.local
```
Fill in your application domain and optional auth/database credentials:
```env
NEXT_PUBLIC_APP_DOMAIN="localhost:3000"
NEXT_PUBLIC_APP_NAME="Linkify Pro"
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Production Build
```bash
npm run build
npm run start
```
