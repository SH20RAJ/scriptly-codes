## 🚀 Quick Start (1-2-3 Setup)

### Step 1: Unpack the Files
Extract `velour-kinetic-portfolio.zip` to your project folder.

### Step 2: Open Locally
Double-click `index.html` to run immediately in your web browser. No npm, build chains, or node_modules needed!

### Step 3: Deploy Online
Deploy with one command to any static hosting:
- **Netlify / Vercel**: Drop folder into web dashboard.
- **Surge**: Run `npx surge . your-domain.surge.sh`.
- **GitHub Pages**: Push repository and enable Pages in settings.

## 🎨 Customization Guide

### 1. Changing Brand Colors
Open `assets/css/style.css`:
```css
:root {
  --bg: #090a0f;           /* Deep obsidian background */
  --orange-1: #f59e0b;     /* Primary amber/gold accent */
  --accent-glow: rgba(245, 158, 11, 0.35);
}
```
Swap `--orange-1` to violet (`#8b5cf6`), neon lime (`#c1ff72`), or cyber cyan (`#06b6d4`) for instant aesthetic rebranding.

### 2. Updating Portraits & Names
- Replace portraits in `assets/images/portrait-1.jpg` through `portrait-15.jpg`.
- In `index.html`, adjust member names and titles in `<div class="nm">` and `<div class="rl">`.
