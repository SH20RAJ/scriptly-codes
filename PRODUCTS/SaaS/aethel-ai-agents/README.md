# ⚡ AETHEL — Autonomous AI Agents & Neural Workflow Template

Thank you for purchasing from [Scriptly Store](https://scriptly.store/)!

Aethel is an ultra-modern, high-converting SaaS landing page designed for autonomous AI agent platforms, developer infrastructure, and enterprise deep-tech startups.

---

## 🚀 Features
- **Live Interactive Sandbox**: Real-time terminal output simulator with task switching.
- **Micro-interactions & Glow Shimmers**: Tailored dark mode styling with GPU-accelerated gradient fills.
- **Interactive Pricing Calculator**: Monthly and Annual pricing toggle with instant token discounts.
- **Enterprise Bento Grid**: Highlights agent swarms, vector memory, and sandboxed security.
- **100% Lightweight**: Pure vanilla HTML5, CSS3, and JavaScript — no build steps, node_modules, or hydration delays required.
