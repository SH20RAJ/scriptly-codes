Frequently Asked Questions

How does Aethel prevent agent hallucination loops?

Aethel implements multi-agent adversarial consensus. When a primary agent generates code or external mutations, a separate auditor agent evaluates the diff in a dry-run sandbox before changes are committed.

Can I bring my own LLM API keys or local weights?

Yes. Aethel is completely model-agnostic. You can plug in Anthropic, OpenAI, DeepSeek, or run self-hosted vLLM/Ollama clusters behind your private VPC.

What security isolations are provided for tool execution?

Every tool invocation runs in an ephemeral Firecracker MicroVM with strictly bounded network egress, disposable file systems, and real-time AST validation.
