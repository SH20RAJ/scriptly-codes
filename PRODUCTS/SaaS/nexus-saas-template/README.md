# ⚡ NEXUS — Next.js 16 & Tailwind v4 Modern SaaS Template

A bleeding-edge, high-converting B2B SaaS marketing website and landing page built with **Next.js 16**, **Tailwind CSS v4**, **shadcn/ui**, and **Radix UI**.

Live Demo: [https://nexus-saas.surge.sh](https://nexus-saas.surge.sh)  
Official Store Listing: [https://scriptly.store/products/nexus-saas-template](https://scriptly.store/products/nexus-saas-template)

---

## 🚀 Key Highlights
- **Bleeding-Edge Foundation**: Built on Next.js 16 App Router and the brand-new Tailwind CSS v4 engine.
- **Bento Grid Architecture**: Showcases product metrics, security guarantees, performance graphs, and workflow triggers.
- **Interactive Tier Pricing Matrix**: Flexible pricing cards with instant currency and billing period toggles.
- **Fluid Dark / Light Themes**: Integrated theme switcher with smooth CSS transitions and accessible color contrast.
- **Enterprise Social Proof & FAQ**: Customer testimonial carousels, company logo tickers, and accessible animated accordions.
- **Mobile First**: 100% responsive navigation drawer and fluid viewport scaling.

---

## 🛠️ Tech Stack
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/) & [Radix UI](https://www.radix-ui.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Radix Icons](https://icons.radix-ui.com/)

## 🚀 Quickstart

### 1. Install Dependencies
```bash
pnpm install
# or
npm install
```

### 2. Run Development Server
```bash
pnpm dev
# or
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Build for Production
```bash
pnpm build
pnpm start
```
