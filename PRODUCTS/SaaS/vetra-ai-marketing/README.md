# ⚡ VETRA — Autonomous AI Marketing Platform & SaaS Template

An enterprise-ready AI marketing automation landing page and web application template engineered with **Next.js 15**, **Tailwind CSS**, **Framer Motion**, and **shadcn/ui**.

Live Demo: [https://vetra-saas.surge.sh](https://vetra-saas.surge.sh)  
Official Store Listing: [https://scriptly.store/products/vetra-ai-automation](https://scriptly.store/products/vetra-ai-automation)

---

## 🌟 Key Features
- **Fluid Animation Choreography**: Powered by Framer Motion with scroll-linked timelines, glowing halo headers, and hover transformations.
- **Interactive Automation Visualizer**: Showcase AI workflows, trigger actions, and connected API nodes in real-time.
- **Dynamic Pricing Calculator**: Toggle between monthly and annual billing with interactive discount badges and feature matrices.
- **Enterprise Bento Grid**: Modular, responsive feature cards highlighting sub-40ms execution, neural reasoning, and multi-channel automation.
- **Comprehensive UI Component Suite**: Built on top of Radix UI primitives with full keyboard accessibility and dark-mode optimization.
- **Zero Config Setup**: Clean TypeScript App Router architecture with modular component trees.

---

## 🛠️ Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Component Primitives**: [shadcn/ui](https://ui.shadcn.com/) / [Radix UI](https://www.radix-ui.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & Number Flow
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Quickstart Guide

### 1. Installation
```bash
npm install
# or
pnpm install
# or
yarn install
```

### 2. Development Mode
Run the development server locally:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
