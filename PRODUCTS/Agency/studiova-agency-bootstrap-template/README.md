## 🎨 Customization Guide

### 1. Changing Brand Colors
Open `assets/css/styles.css`. Studiova uses standard CSS custom properties:
```css
:root {
  --bs-primary: #C1FF72; /* Neon Lime Accent */
  --bs-dark: #000000;    /* Background / Dark accents */
}
```
Modify `--bs-primary` to match your brand's unique signature color.

### 2. Updating Logos & Images
- **Logos:** Replace `assets/images/logos/logo-white.svg` and `logo-dark.svg` with your SVG or PNG logos.
- **Favicon:** Replace `assets/images/logos/favicon.svg`.
- **Hero Video:** Replace `assets/images/backgrounds/banner-video.mp4` with your brand reel or MP4 video.
- **Team & Portfolio Photos:** Replace the files inside `assets/images/team/` and `assets/images/portfolio/`.

### 3. Modifying Typography
The template uses Google Fonts **Manrope**. To change the font family, update the `@import` URL in `assets/css/styles.css`:
```css
@import url("https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@300..800&display=swap");
```
