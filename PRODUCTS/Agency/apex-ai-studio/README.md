# 🎨 APEX — Cinematic AI Agency & Interactive Studio Template

A visually stunning, high-converting digital agency and AI startup landing page built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**.

Live Demo: [https://apex-studio.surge.sh](https://apex-studio.surge.sh)  
Official Store Listing: [https://scriptly.store/products/apex-ai-studio](https://scriptly.store/products/apex-ai-studio)

---

## 💎 Features
- **Atmospheric Dark Visuals**: Bespoke dark space aesthetics, glowing ambient light cones, and subtle starry backgrounds.
- **Framer Motion Micro-Interactions**: Orchestrated entrance animations, floating badge elements, and buttery-smooth section reveals.
- **Lottie Micro-Animations**: Embedded lightweight vector animations for engaging user feedback and feature demonstration.
- **Social Proof & Client Grid**: Showcase enterprise partners, client testimonials, and satisfaction metrics.
- **High-Converting Lead Gen**: Optimized call-to-action sections engineered to maximize appointment bookings and product trials.
- **SEO & OpenGraph Optimized**: Complete meta tags, social sharing cards, and responsive viewport configurations.

---

## 🛠️ Tech Stack
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/) & [DotLottie](https://dotlottie.io/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

### 1. Installation
```bash
npm install
# or
bun install
# or
pnpm install
```

### 2. Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
