# 🏛️ LUMEN — Editorial Architecture & Spatial Atelier Template

Thank you for purchasing from [Scriptly Store](https://scriptly.store/)!

Lumen is an ultra-luxury editorial architecture, interior design, and spatial atelier HTML5 template built for high-end architects, monographs, and boutique real estate developments.

---

## 🌟 Highlights
- **Editorial Typography**: Styled with Italiana, Syne, and Plus Jakarta Sans for an architectural magazine aesthetic.
- **Interactive Spatial Scope Estimator**: Live slider calculating engineering and construction schedules based on square footage.
- **Filterable Monograph Grid**: Real-time project categorization with high-resolution image hover interactions.
- **Materiality Swatch Board**: Tactile presentation of stone, timber, bronze, and concrete materials.
- **Client Inquiry Flow**: Built-in multi-input architectural commission brief.

---

## 🛠️ Quick Setup
1. Unzip the project folder.
2. Open `index.html` to update your studio name, project images, and contact information.
3. Deploy directly to Surge:
   ```bash
   npx surge ./ lumen-atelier.surge.sh
   ```
