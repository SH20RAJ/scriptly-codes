# DevCraft — Modern Full-Stack Engineer Portfolio & SaaS Template

A production-grade developer portfolio, blog, and project showcase built on **Next.js 16**, **Tailwind CSS**, and **Framer Motion**. Designed for software engineers, full-stack creators, and indie hackers who want to command high rates, attract enterprise recruiters, and convert visitors into clients.

---

## 🌟 Key Engineering Features

- **⚡ Next.js 16 & React 19**: App Router architecture with static site generation (SSG) and lightning-fast edge delivery.
- **📊 Real-Time GitHub Activity Matrix**: Interactive open-source contribution telemetry tracking merged PRs, multi-repo statistics, and commit velocity.
- **⌨️ Keyboard-Driven Command Palette (⌘K)**: Global spotlight search for quick navigation across projects, blogs, work experience, and theme controls.
- **✍️ MDX Blog & Technical Monograph Engine**: Built-in syntax highlighting via Shiki with customizable themes and remark/rehype pipelines.
- **🎨 Dark & Light Mode**: Seamless theme switching with persistent localStorage hydration and zero flicker.
- **📱 Responsive Bento Grid Layout**: Tailored viewports for desktop, tablet, and mobile devices.
- **📈 SEO & Open Graph Optimized**: Dynamic metadata generation, JSON-LD structured data, and automated sitemap support.

---

## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS, Lucide Icons, Radix UI Primitives
- **Animations**: Framer Motion & CSS keyframes
- **Content**: MDX, gray-matter, Shiki syntax highlighter
- **Type Safety**: 100% TypeScript strict mode
